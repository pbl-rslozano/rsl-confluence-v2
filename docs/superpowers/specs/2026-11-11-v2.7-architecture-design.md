## 2. Work packages (one release, v2.7.0)

### WP12 — Stablecoin quote pairing

**12.1 Quote registry** (`src/lib/quotes.ts`, new). One table of stablecoin quotes with peg currency:
USD-pegged `USDT USDC FDUSD USD1 USDE RLUSD XUSD U PYUSD DAI TUSD USDG BFUSD`, EUR-pegged `EURI EURC`. Fiat quotes
(`USD`, `EUR` books on Bybit/Bitget) are **not** stablecoins and stay out. `splitPair(symbol, venueMeta?)` returns
`{base, quote}` from venue metadata when known, else by longest known-quote suffix (`BTCFDUSD` → BTC/FDUSD, `BTCPERP` →
BTC/USDC on USDC-perp venues). Every former `replace(/USDT$/…)` site uses it (F2).

**12.2 Venue metadata (no new host).** Read once per 6 h per source, like v2.2 instrument types:
Binance `/api/v3/exchangeInfo?showPermissionSets=false` (weight 20; `baseAsset`/`quoteAsset`/`status`), Bybit
instruments-info (already read; now also keeps `baseCoin`/`quoteCoin`/`settleCoin`), Bitget `/api/v2/spot/public/symbols`
and `/api/v2/mix/market/contracts?productType=USDC-FUTURES`. On failure: suffix parsing, scan continues. The quote menu is
built from what the venue lists **now** (∩ registry), so delisted coins disappear by themselves.

**12.3 Quote setting (per source).** Header control **Quote**: `USDT` (default, = v2.6 behaviour, byte-identical
results), any listed stablecoin, or **Best USD stablecoin** — per coin, the USD-pegged pair with the highest USD
volume. Perpetuals: `USDT` / `USDC` (Bybit linear settle coin, Bitget `USDC-FUTURES`) / Best. Coins.ph stays **PHP** (its
USDT/USDC books are thinner than the peso books; the menu says so). EUR-stablecoin quotes are offered only as an explicit
choice, so every scan has one price currency (USD, EUR or PHP).
- *Best* keeps the previous pick for a coin unless another quote's USD volume is ≥ 25 % higher (hysteresis), so the
  ledger does not flip between `BTCUSDT` and `BTCUSDC` from scan to scan.
- *Indicators always use one real pair's candles.* No synthetic multi-quote candles (they invent highs/lows and turn a
  depeg into a fake price move).
- The pair symbol already contains the quote, so ledger, history store, watchlists and paper keep different quotes
  apart without a schema change. Saved scans and watchlists store the quote (older ones load as USDT).

**12.4 Classification and volume.** A non-USDT pair is classified as its USDT twin (`base + "USDT"`), as Coins.ph
already does; a stablecoin base on a USD-pegged quote is excluded (flat). 24 h volume is converted to USD with the
quote's own price on the same venue from the same ticker call (`USDCUSDT`, `FDUSDUSDT`, `EURIUSDT`); if that price is
missing, a USD-pegged quote counts at 1.00 and the row is marked "≈"; a EUR quote without a venue price uses the
WP13 EUR rate, else "USD value unavailable" (ranked last). Turnover floors stay in USD.

**12.5 Depeg monitor (information only).** Each scan reads the selected quote's price against USDT on the venue
(free: same ticker), and USDT against USD from the WP13 rate table. A deviation ≥ 0.5 % shows a **watch** note, ≥ 1 %
**warning**, ≥ 2 % **severe** banner naming the coin, the venue and the reference; it never votes, never mutes a
signal and never blocks a scan. (Thresholds are starting values; F4 shows single-venue spikes, so the banner says
"on this exchange".)

**[as built]** Binance and Bitget spot metadata are read only in non-USDT modes (USDT mode makes the same requests as
v2.6). Saved scans and watchlists do not store the quote; it is a per-source preference (backed up with preferences).
Best considers only quotes the venue lists in the same ticker call.

**Acceptance:** SQ-1 USDT mode results byte-identical to v2.6.0 on fixtures (all venues); SQ-2 `splitPair` golden
(BTCFDUSD, ETHUSD1, BTCPERP, SOLEURI, 1000PEPEPERP, USDCUSDT, XUSDT, AXSUSDT); SQ-3 USDC mode on Bybit/Bitget spot
fixtures returns only USDC pairs with volume converted at USDCUSDT; SQ-4 Best picks the deepest pair with hysteresis;
SQ-5 USDC perps on Bybit (`category=linear`, `BTCPERP`) and Bitget (`productType=USDC-FUTURES`) for tickers, klines and
history; SQ-6 `baseOf("BTCFDUSD")` = BTC cluster; SQ-7 depeg tiers 0.5/1/2 %; SQ-8 browser: Quote menu lists only the
venue's live quotes and a USDC scan shows a quote badge.

### WP13 — Display currency (any fiat) with honest rates

**13.1 Rate source and order.** `src/lib/fx-rates.ts` (new):
1. **Frankfurter v2** `GET https://api.frankfurter.dev/v2/rates?base=USD` — central-bank blend, per-currency sources
   available. Only `type: currency` rows from `/v2/currencies` (cached 30 days) are offered; crypto rows are ignored.
2. **Fallback** fawazahmed0 `cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies/usd.min.json`, then
   `latest.currency-api.pages.dev/...` — labelled "community aggregate, method not published".
3. **Last resort, offline:** official pegs built in — SAR 3.75 (SAMA), AED 3.6725 (CBUAE), QAR 3.64 (QCB),
   OMR 0.3845 (CBO), BHD 0.376 (CBB), JOD 0.709 (CBJ). Any other currency without a rate shows USD and says why.

Fetched at most once per 6 h (and on demand from Settings), cached on the device with its date and source; older than
3 days → **stale** label; never more than one source per refresh unless the previous one failed. Validation: finite,
> 0, ISO code `^[A-Z]{3}$`. A rate that moves > 20 % from the cached one is still used (hyperinflation is real) but
the info line shows the change.

**13.2 Display only.** Engine, ledger, paper book, alerts, recorder and MCP stay in the scan's native currency
(USD ≈ USDT, EUR or PHP). Conversion happens at formatting time: price, volume, key levels, FVG ranges, chart axis and
readout. 24 h % is the native market's change. Release check **R21** fails if `fx-rates.ts` or the display-currency
hook is imported by the engine, scan pipeline, ledger, paper, risk engine, recorder or MCP.

**13.3 Honest labelling.** Stablecoin prices are converted at **1 USDT = 1 USD** (stated in the info line, with today's
USDT/USD from the table and the WP12.5 depeg warning). We do not multiply prices by a crypto quote for USDT: the
reference table is official fiat; mixing in a stablecoin's market price would make every price move with it. The
footer/info line shows "1 USD = 3.75 SAR · Frankfurter (central-bank rates) · 11 Nov 2026 · peg (SAMA)". Pegged
currencies say **peg**; HKD says **band 7.75–7.85**; currencies with parallel markets (ARS, NGN, EGP, LBP, VES) say
**official rate**.

**13.4 Setting.** **Display currency**: *Auto* (default; the device's region → its currency via a built-in region table,
USD when unknown — never from the IP), *USD*, or any listed fiat (searchable). Stored in preferences (backup includes
it). Formatting uses `Intl.NumberFormat` (`style: currency`, `currencyDisplay: "symbol"`, ISO minor units) with the app's
existing significant-digit rules for small crypto prices; `$` alone is shown only for USD.

**13.5 Hosts.** New `connect-src` hosts: `https://api.frankfurter.dev`, `https://cdn.jsdelivr.net`,
`https://latest.currency-api.pages.dev` (web meta CSP and Tauri CSP). GET only, no credentials, JSON parsed and
validated, never executed (`script-src` unchanged). The service worker already passes cross-origin requests to the
network (never cached). ADR-0015 (new) + ADR-0003 amendment v2.7; **R8 now reads its allowlist from `public-hosts.ts`**
(`CSP_HOSTS`), fixing F7, so R8, R16 and the CSPs share one table.

**[as built]** The currency list comes from Frankfurter `/v2/currencies` (cached 30 days), falling back to `Intl`'s ISO
list. Rates are fetched only while a non-USD display currency is shown. Formatting lives in `src/lib/money.ts` (one
formatter for table, detail sheet, key levels, FVG ranges and the chart). Coins.ph also shows USDT's peso premium against
the official rate.

**Acceptance:** FX-1 Frankfurter parser golden from the recorded response (fiat only, metals/crypto dropped);
FX-2 fallback order and labels; FX-3 peg table used offline; FX-4 cross-rate PHP→SAR via USD; FX-5 formatting (JPY 0
decimals, KWD 3, small prices, RTL); FX-6 R21 display-only boundary; FX-7 browser: switching to SAR converts table,
detail sheet and chart axis and shows the source line; FX-8 stale label after 3 days.

### WP14 — Chart full screen, zoom and pan

**14.1 View window.** `PriceChart` keeps a view `{end, count}` over the loaded candles. The depth menu (60/250/1K/All)
sets `count`; zoom and pan move inside all saved bars (minimum 20 bars). Indicators are computed on the **full** series and
then sliced (fixes F5 band gap); VWAP is labelled **VWAP (visible range)**; the hover index is clamped to the view
(fixes the F5 crash).

**14.2 Input.** Zoom anchored at the bar under the cursor or pinch centre; never CSS scaling.
- Mouse/trackpad: Ctrl/⌘ + wheel or trackpad pinch (wheel with `ctrlKey`) zooms; Shift + wheel or horizontal wheel
  pans; drag pans; double-click resets. In full screen plain wheel zooms.
- Touch: two-finger pinch zooms, one-finger horizontal drag pans, vertical drag still scrolls the sheet
  (`touch-action: pan-y`; `none` in full screen), double-tap resets, tap inspects a candle.
- Keyboard: `+`/`−` zoom, `0` reset, `Shift+←/→` pan, `F` full screen, `Esc` leaves full screen; ←/→/Home/End inspect.
- Buttons: Zoom in, Zoom out, Reset view, Full screen / Exit full screen (labelled, 44 px touch targets on phones).
Page zoom stays enabled (no `user-scalable=no`, WCAG 1.4.4).

**14.3 Full screen per platform.**
| Platform | How |
|---|---|
| Desktop browsers, Android Chrome/PWA | Fullscreen API on the chart frame; Esc/system back exits; `fullscreenchange` keeps state in sync |
| iPhone/iPad Safari, iPhone PWA, Capacitor (Android + iPhone) | **Focus view**: fixed overlay over the whole viewport (`100dvh`, safe-area insets, page scroll locked, focus kept in the chart); the status bar is hidden on Capacitor through the adapter |
| Desktop app (Tauri) | Focus view + window full screen through `adapters.window.setFullscreen` (`core:window:allow-set-fullscreen`, the only new capability; R6 lists it) |
In full screen the SVG takes the frame's measured size (ResizeObserver) so candles use the whole screen, and Esc or
Android Back leaves full screen first without closing the detail sheet (window capture listener ahead of Radix).
Orientation lock is not used (no new plugin; Android 16+ ignores it on large screens) — the guide suggests rotating.

**[as built]** Candles are thinned to at most one per 1.5 px (buckets keep true OHLC; the readout says *n bars per
candle*), static layers are memoised so pointer moves redraw only the crosshair (review #6). The menu label stays
"VWAP"; the legend says "VWAP (visible)". Chart toolbar text is English (as the v2.6 chart text was).

**Acceptance:** CH-1 hover clamp (no throw when depth shrinks); CH-2 Bollinger equals the full-series band on the first
visible bar; CH-3 zoom math anchored and clamped (unit); CH-4 browser: Ctrl+wheel zooms, drag pans, Reset restores;
CH-5 browser: Full screen opens a frame filling the viewport, Esc closes it and the sheet stays open; CH-6 phone viewport:
two-finger pinch (CDP touch) changes the visible bar count; CH-7 Tauri capability contains only the added fullscreen
permission.
