## 1. What was found (evidence)

| # | Finding | Evidence |
|---|---|---|
| P1 | **Coins.ph is the only Philippine exchange with a public, keyless market-data API.** REST `https://api.pro.coins.ph`, WebSocket `wss://wsapi.pro.coins.ph`. Public: ping, time, exchangeInfo, depth, trades, klines, 24 h / price / book tickers. Klines `GET /openapi/quote/v1/klines` (`symbol`, `interval`, `startTime`, `endTime`, `limit` default 500, max 1000); intervals 1m–1M (no 1s). Rows are the first 11 Binance kline fields in Binance order. | Official docs source `coins-docs/coins-docs.github.io` (last commit 9 Sep 2026); CCXT 4.5.92 `coinsph` |
| P2 | **Rate limit: 120 per minute per IP** since 16 Mar 2026 (was 1,200); whether it counts requests or summed request weight is not stated [unverified]. 429 → back off; continuing → 418 IP ban 2 min–3 days; `Retry-After` on both; 403 = WAF. A full 24 h ticker costs weight 40. CCXT still assumes 1,200/min. | Coins.ph docs changelog 2026-03-16 |
| P3 | **No public PDAX market-data API was found** (strong inference, not proof: its REST reference `doc.restapi.pdax.ph` could not be opened). Its REST docs are closed to crawlers; every API surface found (PDAX Connect, OTC) is partner/onboarding-only; not in CCXT. GCash GCrypto runs on PDAX; Maya (Coinbase liquidity), GoTyme (Alpaca) and UnionBank are buy/sell apps with no public API. **None found that can be integrated keyless.** | PDAX, GCash, Maya, GoTyme pages; CCXT exchange list; CoinGecko PH exchange list |
| P4 | **Liquidity is thin and mostly remittance flow.** Coins.ph ≈ $24–48 M/day (two CoinGecko snapshots); ~89 % is USDT/PHP and USDC/PHP; BTC/PHP ≈ $0.3–1 M/day; 43 coins / 70 pairs (PHP, USDT, USDC quotes). Global USDT books are orders of magnitude deeper. | CoinGecko (Trust Score 7/10), Nov 2026 |
| P5 | **CORS refused; no geo-block.** Live probe PH-1 from the production web origin: Binance and Bybit controls 200, every Coins.ph call blocked by the browser ("No 'Access-Control-Allow-Origin' header"). Same-origin reads from Saudi Arabia returned 200: 184 symbols (PHP 141, USDT 34, USDC 7), lower-case `status`, 11-field klines, 8h native, weight header `x-sapi-used-ip-weight-1m` (the limit is counted in weight). | `docs/research/evidence/coinsph-probe-2026-11-07.json` |
| P6 | **Code assumes USDT quotes.** `market-client.ts` filters `endsWith("USDT")` and strips `(USDT|USD)$`; turnover floor is in USD. CSP lives in `src/lib/csp.ts` and `tauri.conf.json`. `capacitor.config.ts` does not enable CapacitorHttp, so mobile fetches are subject to CORS today. | `main` @ a90bfc9 |
| P7 | **Regulation.** BSP-licensed VASPs running public order books: Coins.ph and PDAX only (BSP freeze on new licences since 1 Sep 2022, extended indefinitely). SEC CASP rules (MC 4 & 5 of 2025) in force since 5 Jul 2025. In Aug 2025 the SEC listed 15 unregistered offshore exchanges incl. **Bybit and Bitget** (both existing sources); PH ISPs blocked their websites by DNS. Access from Saudi Arabia is unaffected; API-host blocking inside PH is unconfirmed. No rule found restricting reading public prices. | BSP/SEC via BitPinas, Philstar, Inquirer, Tribune (not legal advice) |
| P8 | **Build protection today.** Next.js production builds minify (SWC) and do not emit browser source maps by default, but nothing checks it; no obfuscation; no check that shipped APK/IPA/desktop bundles contain no maps. Update manifest already carries APK size + SHA-256 (`update-channel.ts`). | `next.config.ts`, `release.yml`, `update-channel.ts` |

## 2. Work packages

Delivered as one release, **v2.6.0**, on a branch merged to `main` through a pull request. Order: §3.

### WP7 — Coins.ph source (`coinsph`, label "Coins.ph (PH)")

**7.0 Probe first (gate for the fetch path).** From the deployed web origin, an Android build, an iPhone build and the
desktop app: `GET /openapi/v1/time` and `GET /openapi/quote/v1/klines?symbol=BTCPHP&interval=1h&limit=3`. Record the
status, `Access-Control-Allow-Origin`, and any geo response into `docs/research/evidence/coinsph-probe-<date>.json`
(acceptance **PH-1**). The result picks one of two paths, recorded in ADR-0013. **[as built]** Probe result: CORS
refused → the second row below. `connect-src` is unchanged (no new CSP host); the PDAX REST reference still would
not load in the browser pane, so the PDAX exclusion stands as "not found".

| Probe result | Web / PWA | Android / iPhone | Desktop (Tauri) |
|---|---|---|---|
| CORS allowed | direct fetch; `https://api.pro.coins.ph` added to `connect-src` | direct fetch (WebView) | direct fetch; host in Tauri CSP |
| CORS refused | Netlify rewrite, read paths only: `/x/coinsph/openapi/quote/v1/*` and `/x/coinsph/openapi/v1/{time,exchangeInfo}` → `https://api.pro.coins.ph/...` (200). Same-origin, so no new `connect-src` host; no headers, no secrets in the rule | `nativeGet()` in `packages/adapters/capacitor/index.js` calling `CapacitorHttp.request` **explicitly**. The global `CapacitorHttp.enabled` switch stays **off**: it would re-route Binance/Bybit/Bitget too and bypass the CSP | `nativeGet()` in `packages/adapters/tauri/index.js` via `@tauri-apps/plugin-http`, capability scope limited to the same read paths |

Native HTTP is not policed by the CSP, so the allowed URLs live in one table, `apps/confluence/web/src/lib/public-hosts.ts`
(next to `csp.ts`; **[as built]** `csp.ts` keeps its literal `CONNECT_SRC`, unchanged, because no new CSP host was needed). The app passes the table to `nativeGet()`, which refuses any
other URL; release check **R16** compares the table with ADR-0003, the Tauri scope and the Netlify rules.
Rewrite rules live in a new `apps/confluence/web/public/_redirects` (Netlify). The local PWA launcher
(`tools/pwa-launcher/serve-pwa.mjs`) gets the same read-path proxy, listed in `tools/egress-manifest.json` (R11). On any
other static host the rewrite does not exist and Coins.ph shows **Blocked or unreachable**. **[as built]** The service worker treats `/x/` as
market data (network-only, like `/api/`): before this, its stale-while-revalidate shell rule cached the same-origin
rewrite, so peso data lagged one scan and an outage still read OK. Acceptance **PH-13** checks that no `/x/` response
is ever in the offline cache. The currency label, PH premium and thin count now change together with the rows they
describe, so the previous source's rows are never shown with ₱ while a Coins.ph scan is still scoring.
Trade-off of the rewrite path: requests leave from Netlify's shared edge IPs, which other Netlify sites also use, so a
Coins.ph 429/418 could hit this app without the user causing it. Acceptable for a personal edition; ADR-0013 records it.

**7.1 Quote-currency layer.** `DATA_SOURCES` gains `quotes: ["PHP","USDT","USDC"]`. Symbols are parsed from
`exchangeInfo` (`baseAsset` / `quoteAsset`), never by suffix regex. 24 h quote volume is converted to USD with the
venue's own USDT/PHP last price; if that price is missing the source is ranked by native volume and shows "USD value
unavailable" — no invented rate. Binance/Bybit/Bitget behaviour is unchanged (golden tests).

**7.2 Classification.** USDT/PHP and USDC/PHP are the Philippine peso against the dollar via stablecoins: classified
**Currency (FX)**, not crypto, so they never top a crypto scan. Every other `XXX/PHP` pair is crypto quoted in pesos.

**7.3 Candles.** Reuse the Binance kline parser on fields 0–10. Interval map 1:1 for 1m–1M (Coins.ph serves 8h natively); only 2d/4d are
synthetic, via the existing epoch-anchored aggregation. `limit ≤ 1000`; history paging always sends `endTime` (CCXT note). Closed-bar,
freshness and contiguity rules apply unchanged.

**7.4 Rate budget (120/min/IP).** The limit's unit is unconfirmed, so the budget assumes the stricter reading and counts
**weight**: token bucket of **100 weight/min** (headroom), ≥ 600 ms between requests, top-N capped at **40** for this
source, auto-refresh not faster than **5 min**. A scan costs one 24 h ticker (weight 40) + ≤ 40 klines (weight 1 each,
per CCXT) = ≤ 80. **New code:** today `rateLimitedUntil` in `market-client.ts` is module-wide, so a Coins.ph 418 would
also pause Binance, Bybit and Bitget; v2.6 makes the cooldown **per source** and honours the full `Retry-After`
(a 418 can last up to 3 days, not the current 10-minute default).
WebSocket kline streams (`wsapi.pro.coins.ph`, up to 1,024 streams per connection) are deferred to v2.7.

**7.5 Thin-market rule.** A PHP pair is scored only if its USD-equivalent 24 h turnover ≥ **$250 k** (start value;
recalibrated from the ledger after 30 days). **[as built]** Thin pairs are not scanned at all (no candles requested,
which also saves rate budget); the note above the list counts them and lists them on hover.

**7.6 PH premium (information only).** For coins listed on both Coins.ph and the global source:
`premium % = PHP price ÷ (global USDT price × Coins.ph USDT/PHP) − 1`. Shown in the detail sheet; it **does not
vote** (enrichment rule from the missing-capabilities research). Engine config id unchanged. **[as built]** Global
price = one public Binance `/api/v3/ticker/price` call per scan. Ledger logging is deferred to v2.7: the ledger CSV
schema is fixed and its `basis_pct` field drives the band-pinned mute, so it must not be reused for the premium.

**7.7 Ledger and costs.** Own source id `coinsph`; fee assumption configurable and conservative until the Coins.ph fee
schedule is confirmed [unverified].

**7.8 Not integrated: PDAX, GCash, Maya, GoTyme, UnionBank.** Reason: no keyless public market data found (P3).
WP7.0 also opens `doc.restapi.pdax.ph` by hand; if it documents keyless market data, PDAX is re-planned. ADR-0013
records the revisit trigger: PDAX publishes a public market-data API.

**7.9 Node processes.** Recorder: Coins.ph only if the owner turns it on; then `api.pro.coins.ph` joins the recorder
entry in `tools/egress-manifest.json` (R11). MCP: still no hosts.

**Acceptance:** PH-1 probe evidence; PH-2 parser golden from a recorded live response; PH-3 PHP→USD conversion and Thin
badge; PH-4 simulated 30-min auto-refresh never exceeds 100 requests/min; PH-5 on the web an opaque fetch failure is labelled
"Blocked or unreachable", never "Rate limited"; native shells report the real status; PH-6 USDT/PHP lands in Currencies; PH-7 premium visible and engine config id unchanged;
PH-8 Binance/Bybit/Bitget results byte-identical to v2.5.1 on fixtures.
**Docs:** ADR-0013 (new), ADR-0003 amendment v2.6, user guide §"Sources" and §"Philippine market".

### WP8 — Code protection build (owner's `html-app-protection-build` pipeline, adapted to a Next.js export)

What it does and does not do: client code that runs on the user's device can always be read; the app keeps no secrets
by design. Protection here deters copying and casual tampering. Integrity for users comes from signing (WP10.4).

| Stage | v2.6 implementation |
|---|---|
| 1 Master source | Each release tags `main` and stores `rsl-confluence-<ver>-MASTER_SOURCE.zip` + SHA-256 in `build-manifest.json` (CI artifact, never shipped). The source commit SHA is injected into `BUILD_INFO` at build time (new field `commit`) and shown in About. |
| 2 Structure | Already modular (TypeScript modules, workers); no inline-script extraction needed. |
| 3 Minify | Next/SWC production minification (exists); `productionBrowserSourceMaps: false` set explicitly. |
| 4 Obfuscate own code only | `tools/protect-build.mjs`, pinned `javascript-obfuscator`, runs on `out/` after `next build` and before Capacitor/Tauri packaging. Targets the app's own chunks (app routes, `src/lib` engine, workers) listed in `tools/protect-targets.json`; excludes React/Next runtime and vendored libraries (byte-identical check). Conservative settings: identifier renaming + string array (**[as built]** string array off — see the measurements below); **no** control-flow flattening (engine speed), **no** self-defending/debug-protection/domain-lock (break under CSP, Capacitor and Tauri origins), no `eval`-based transforms (CSP has no `unsafe-eval`). |
| 5 No maps | No `.map` files, no `sourceMappingURL`/`sourceURL` comments, no inline maps in `out/`, the APK, the IPA or the desktop bundles. |

After stage 4 the service-worker version and precache list are regenerated (keeps R15). The same protected `out/`
feeds web, Android, iPhone and desktop. Recorder and MCP (Node, owner's machine) are not obfuscated.

**Audit practice kept:** the owner audits compiled bundles as ground truth. Each release keeps the minified,
un-obfuscated `out/` (`dist-minified`) as a CI artifact, linked by hash in `build-manifest.json`; REA/static audits
run on it, and R18 proves the protected build behaves the same.

**Acceptance:** BG-1 no source maps anywhere in shipped artefacts; BG-2 vendor chunks byte-identical to the minified
build; BG-3 protected build passes the full acceptance suite; BG-4 engine golden replay through the protected engine
equals the minified build bit-for-bit; BG-5 protected bundle size and first-scan time within +15 % of minified.

**[as built]** Measured on build 20261107 (html target):
- *Settings.* Identifier renaming (hexadecimal), compaction and simplify only. **The string array is off**: even
  without encoding it made engine scans 2.7× slower (strings read in hot loops go through a lookup call), against the
  +15 % cap; with it off the protected engine is −0.1 %. Turbopack ships no file names, so own chunks are picked by
  content markers in `tools/protect-targets.json` (8 chunks: engine, both workers, page, app shell, core kit, web
  adapter); the Capacitor and Tauri adapter chunks bundle vendor SDKs and stay untouched. The raw worker `.ts` files
  Turbopack copies into `_next/static/media/` are removed.
- *BG-3:* 128/128 acceptance on the protected build. *BG-4:* `tools/protect-golden.mjs` replays 120 series (4
  timeframes × 5 regimes × 3 lengths × crypto/FX) through `runScanJobSafe` in both builds — 120/120 identical.
- *BG-5:* "bundle size" means total chunk JS shipped: +3.5 % raw, +1.7 % gzip (R17 fails above +15 %). Scan time
  −0.1 % (BG-4 tool fails above +15 %). For information, the 11 files loaded at start grow +28 % raw, +15.8 % gzip
  (about 100 KB once, then cached), because renamed identifiers are longer than SWC's.
- *R18:* CI writes `build-golden.json` and `build-evidence.json` after acceptance and checks them against the
  protected tree hash in `build-manifest.json`. `tools/release-check.mjs` runs R17/R18 when a build is present
  (`--require-build` makes a missing build fail). The master source zip field exists in the manifest; producing the
  zip is still open (release check `--require-master` not yet used in CI).
**Docs:** ADR-0014 (new), user guide §"Official builds".

### WP9 — Release gates (block a release that could hurt the app or its users)

| Check | Fails the release when |
|---|---|
| **R16** public-host table | a host or path in `src/lib/public-hosts.ts`, the Tauri http scope, the Netlify rewrite rules or the CSP is not in ADR-0003; or a Netlify rule adds headers/secrets or proxies a non-read path. |
| **R17** protected build | any source map or map comment in `out/`, APK, IPA or desktop bundle; an obfuscated file outside `protect-targets.json`; a vendor chunk differs from the minified build; `build-manifest.json` lacks the master SHA-256. |
| **R18** protected equivalence | CI evidence missing that BG-3 and BG-4 passed on this exact protected build hash. |
| **R19** docs parity | the guide's title `rsL Confluence Terminal v<major.minor> <year>` or footer `v<major.minor> <year> · build <YYYYMMDD>` does not match `BUILD_INFO` (`version`, `build`) in `src/lib/build-info.ts`; or a user-visible work package (v2.6: WP7, WP8, WP10, WP11) has no matching `<!-- wp:WPn -->` anchor in `docs/user-guide/en.md`; or the CHANGELOG entry names no plan WP. Arabic guide: flagged for reviewer update, does not block. |
| **R20** keyless public sources | any public-source adapter sends auth headers or signatures, or any app code (not only paper/MCP, extending R12) references a Coins.ph path outside the R16 read allowlist (allowlist, not denylist), or offers Coins.ph in the 🔑 private-API dialog. |

R8 today hard-codes its allowlist and parses `CONNECT_SRC` out of `csp.ts`; in v2.6 it reads the same
`public-hosts.ts` table, so R8 and R16 cannot disagree. R16–R20 join `tools/release-check.mjs`. **[as built]** PH-1…8 and US-2…6 are unit tests
(`src/lib/coinsph.test.mjs`, 53 tests on live probe fixtures) or source-level release checks; browser acceptance adds
PH-9…13, US-1 and US-1b to `tools/acceptance-ids.json` (R14). Cooldowns became per venue for every source, not
only Coins.ph.

### WP10 — User-side safeguards

1. **Source health line** (footer) per source: OK · Slow · Rate-limited until hh:mm · Stale, plus one failure state that depends
   on what the platform can see. On the web a CORS refusal, a DNS block and a 429 without CORS headers all reach
   JavaScript as the same opaque error, so the web shows **Blocked or unreachable**. Native shells see the real status
   and show **Rate-limited** or **Network blocked**. Plain-language help for each; never guesses the user's country. (US-1)
2. **Thin and local-market labels:** **[as built]** while Coins.ph is the source, prices show ₱ and a note above the
   list says the peso market is much thinner than global USDT markets and counts the thin pairs left out. (US-2)
3. **No silent substitution:** a failed source never borrows another source's candles; the scan says which rows are
   missing. (existing rule, now tested: US-3)
4. **Update integrity:** new in v2.6, the Android update notice shows the APK size and SHA-256 from `latest.json`
   visibly (today the SHA-256 is only a tooltip; other platforms carry no file hash). About shows the source commit
   (`BUILD_INFO.commit`) so a user can compare it with the GitHub release. Android refuses an update signed
   with a different key, which keeps data safe from look-alike APKs. Option for v2.7 (owner choice): download the APK
   inside the app, verify SHA-256, then hand it to the installer (needs `REQUEST_INSTALL_PACKAGES`). (US-4)
5. **Read-only promise visible:** Coins.ph is public data only — no account link, no 🔑 profile; paper-only banner
   unchanged. (US-5)
6. **Data notice in About:** market data belongs to each exchange; personal use; Coins.ph API terms not yet reviewed
   [unverified]. (US-6)
