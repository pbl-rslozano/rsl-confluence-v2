# Confluence Terminal v2.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v2.5.0: restored mobile Expand list, real light/dark/system theming, readable language menu, the rsL icon on Android/iPhone, an honest machine-check → human-certification path for 16 languages, and guards against another snapshot overwrite.

**Architecture:** Branch `release/v2.5` from `main` @ `35d1fde`; one PR. Theming remaps Tailwind's neutral scale to CSS variables per `data-theme` instead of rewriting ~600 class uses. Fonts for the language menu are glyph subsets built from pinned `@fontsource` packages. Icons come from the existing Tauri-generated sets and are copied into the Capacitor projects by `tools/apply-native-config.mjs`; a new release check reads them back out of the built APK/IPA.

**Tech Stack:** Next.js 16 static export, Tailwind v4, Capacitor 8.6 (+ `@capacitor/status-bar` 8.0.4, already a dependency), Tauri 2, Playwright + axe (`tools/e2e/acceptance.cjs`), Node 22 test runner, fontTools `pyftsubset` and Pillow (CI only), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-07-v2.5-architecture-design.md` (WP6 update channel is **out of scope** here — deferred until the owner supplies a Netlify token).

## Global Constraints

- Brand strings (`rsL`, `Confluence Terminal`, `by rsLozano`, build stamp, customer name) are never translated; credit only at page end ("Created by rsLozano").
- `packages/core` (rsL Core Kit) unchanged — R4 manifest must still pass; kit issues go to `docs/kit-issues/KIT-xxx.md`.
- Only `packages/adapters` may import `@tauri-apps/*` / `@capacitor/*`.
- Exact pinned versions; `--frozen-lockfile`; lifecycle scripts off; no new runtime hosts (R8 unchanged — fonts and icons are vendored).
- No private keys in artefacts; paper only; engine 2.3.0 / `2c1a18ad8a61e9ab` untouched.
- Version: `2.5.0`, build `20261107` (app-info.ts, package.json, tauri.conf.json, CHANGELOG).
- Every new UI string in all 18 catalogs; tier-2 catalogs never claim `CERTIFIED` without a named reviewer.
- WCAG 2.2 AA in both themes; 48 px targets on coarse pointers; reduced motion respected.

## Review Focus

- Theme set to **System** while the OS flips light↔dark with the app open → app follows live without reload (Task 3 test T-5).
- User with an old `ct-theme=light` or saved `background: "white"` preference upgrades → lands in Light, not System (Task 3 test T-6).
- Expanded list on a phone in **Arabic (RTL)** at 360 px → footer still pinned, nothing after it (Task 2 M-21).
- A `CERTIFIED` catalog edited later without re-review → validator fails (Task 6 unit test `certified-hash-mismatch`).
- Language menu opened at 360 px in RTL → sheet fully on-screen, every native name rendered without fallback boxes (Task 4 ID-8.12b).
