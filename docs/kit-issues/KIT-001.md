# KIT-001 — `.rsl-app` is used for two different things

**Kit:** rsL Core Kit v1.0 2026 · **Found:** 31 Oct 2026 while porting Confluence Terminal · **Severity:** medium (visual)

## Problem
`core/rsl-brand.js → brandBlockHTML()` wraps the app name in `<span class="rsl-app">`, but `ui/rsl-shell.css` also uses `.rsl-app` for the whole application grid (`display: grid; height: 100%; grid-template-areas: …`, and `display: block` under 600 px). Any app that loads `rsl-shell.css` gets the wordmark span turned into a grid/block box, so **"rsL" and the app name break onto two lines** (seen at 390, 820 and 1366 px in Confluence Terminal).

## Proposed kit change (v1.0.1)
1. Rename the wordmark class to `.rsl-appname` in `brandBlockHTML`, `ui/rsl-shell.css` (`.rsl-name .rsl-appname { … }`) and the README.
2. Keep a compatibility rule for one version: `.rsl-name .rsl-app { display: inline; height: auto; grid-template: none; }`.
3. Add a test: render `brandBlockHTML(app)` into a document with `rsl-shell.css`, assert `.rsl-name` is a single line box.
4. Bump to v1.0.1 and regenerate `KIT-MANIFEST.sha256`.

## App workaround (until v1.0.1)
`apps/confluence/web/src/app/globals.css` scopes an override to `.rsl-brand-host .rsl-app` (display inline, grid reset), marked `KIT-001 workaround`. The kit files themselves are unchanged (release-check R4).
